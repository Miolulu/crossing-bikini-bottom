## 1. 风险前置页（批量生成最容易翻车的 4 件事）

| # | 风险 | 后果 | 本包解法 |
|---|---|---|---|
| 1 | **风格漂移** | 跨账号/跨批次生成时描边粗细、饱和度、等角角度不一致，素材摆进同一房间像拼贴 | 风格锚点**逐字复用**；先跑 1 张锁定种子 / 模型版本 / 步数 / 提示词全文并存档（§7 步骤 4、§12 参数存档表）；每生成 3 张抽检 1 张 |
| 2 | **抠图脏边** | 模型自动加落地阴影 / 接触阴影 / 环境光遮蔽，透明底抠完留灰黑毛边，叠到房间背景上极明显 | 负面词逐字排除 `投影，落地阴影，接触阴影，环境光遮蔽`（EN: `shadow, cast shadow, contact shadow, ambient occlusion`）；素材图三铁律：**纯色底 / 主体互不重叠 / 基线齐平** |
| 3 | **效果被画进图** | 把金色交互高亮、呼吸发光、碎星光画进 PNG → 既做不了动画，又污染色板和抠图 | 一切高亮 / 发光 / 呼吸 / 粒子 / 数字由 CSS 叠加；**交互高亮金 `#FFD23F` 严禁入图**；蟹黄堡、门框、光圈、进度条、号码数字继续用 CSS/SVG |
| 4 | **IP 过近** | 直接照描原作赛璐璐描线与精确造型、把招牌文字写进图 → 合规风险，且与 §10「不 1:1 复刻」冲突 | 只写**形体 + 色块 + 圆润比例 + 构图气质**；专有名词仅用于清单索引（人类可读），**禁止写进提示词**；招牌只画轮廓、不写字，文字全部由 HTML 渲染 |

> 另：**位置锚定代替数量词**——不要写「画 6 栋房子」，改成「画面从左到右依次是：左下角的黄色圆果形屋、其右后方的灰色石雕屋……」。空间锚点比计数可靠。

## 10. 降级方案 L1 / L2 / L3（与方案 §8.4 口径一致）

> **成本口径**：AI 生图按「调用次数」计费（1 张成图 ≈ 1 次调用），不同平台 / 模型 / 分辨率单价差异极大，**本包不假定任何具体单价**。给出可复算的调用次数 `C`，用 `总消耗 = C × P`（P = 账号实际单次单价）代入。

| 档位 | 覆盖范围 | 成图张数 | 含试错重抽 ×1.35 | ≈ 调用次数 C | 何时用 |
|---|---|---|---|---|---|
| **L1 降级**（推荐起点） | 世界全景 + 6 建筑外观 + 6 主题房间模板 | ~20 | ×1.35 | **≈ 27** | 先验证风格与整体观感，确认后再扩 |
| **L2 推荐** | L1 + 核心 40 物件 + 7 立绘 + 13 token | ~95 | ×1.35 | **≈ 130** | 风格锁定后的正式批量 |
| **L3 完整** | 14 房间 + 60 物件双态 + 全角色 + 27 彩蛋 + UI | ~220 | ×1.35 | **≈ 300** | 追求完整质感时 |
| 首批「锁风格」 | 1 主体 × 1 状态 | 1–3 | — | **1–3** | 步骤 1，必做 |

代入示例（仅演示，P 需自行核实）：L1 若 P=20 → ~540；P=50 → ~1,350。L2 若 P=20 → ~2,600；P=50 → ~6,500。L3 若 P=20 → ~6,000；P=50 → ~15,000。

**降本策略**：① 先跑 1 张锁风格 / 种子 / 模型版本；② 朝右单一方向 + 代码镜像省一半；③ 换色主体单一纯色平涂，代码替换色值出变体；④ 动态效果一律代码叠加；⑤ 蟹黄堡 / 门框 / 光圈 / 进度条等几何件继续 CSS/SVG；⑥ 每 3 张抽检 1 张防漂移。

**推荐起点**：**L1（≈27 次调用）**——跑 6 栋建筑 + 1 张全景验证风格，确认后走 L2。

**v2.8 增量说明**：三处场地、小游戏会话 UI、吹泡泡与空手道默认**由代码绘制、不产生调用**；若要把三处场地地面（G-10）与玩法主体（G-07 / G-11 / G-12）换成手绘贴图，最多 **+8～11 次**调用（3 地面 + 8 主体，取其一即可），L1 / L2 / L3 估算不变。会话 UI（G-13）与鱼网光标（G-08）**永远不生图**。

**v2.7 增量说明**：捉水母与小蜗功能默认**由代码绘制、不产生调用**；若要把三型水母（G-07）与小蜗造型（G-09）换成手绘贴图，最多 **+5 次**调用（3 + 2），L1 / L2 / L3 估算不变。鱼网光标（G-08）**永远不生图**（SVG data-URI + CSS 动画）。
