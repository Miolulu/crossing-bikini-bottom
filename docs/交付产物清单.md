## 三、交接说明
- 生图账号只需按 **第一节(A~F)** 逐条出图，文件命名用编号（如 `B-05.png`），放入 `images/` 即可被代码按插槽引用。
- 开发侧按 **第二节(K)** 推进，占位几何先跑通最小闭环，生图到位后替换。
- 进度以 `开发日志.md` 为准，每日追加。
- **风格一致性红线（v2.6）**：所有批次必须使用《美术资产规格与提示词包.md》§3 的**逐字风格锚点**，与方案文档 §8.2 完全一致；任一侧改动必须双向同步，否则素材摆在同一房间会露馅。
- **不进图清单（v2.6）**：蟹黄堡五层与咬痕、金色光圈 / 虚线光路 / 物件气泡、进度条、号码屏数字、门牌文字、彩蛋计数、交互高亮与呼吸发光、海草 / 气泡 / 蒸汽动效——均由 CSS/SVG/HTML 绘制，**勿排产生图**（对应方案 §8.3「0 张」）。
- **成本口径**：生图按调用次数计，`总消耗 = C × P`；L1≈27 / L2≈130 / L3≈300 次，不假定单价；**先说明消耗再询问，不擅自生成**。
- **v2.7 新增资产不增量**：三型水母、鱼网光标、网挥动、计数板、小蜗色盘均为纯 CSS/SVG 绘制，L1/L2/L3 估算**不变**；仅「手绘替换水母 + 小蜗」为可选 +5 次（3 + 2），鱼网永远不生图（见方案 §8.5）。
- **v2.8 新增资产仍不增量**：三处场地地面 / 木牌、五段泡泡、木桩沙袋、横幅 / HUD / 结算卡 / 蓄力条 / 招式卡全部纯 CSS 绘制，L1/L2/L3 估算**不变**；若手绘替换最多 +8～11 次（3 地面 + 8 主体，取其一，见方案 §8.6）。
- **v1.0 行为变更（生图侧需知）**：默认街上**不出现水母**，水母贴图只在「捉水母」玩法中显示；三处场地是世界内可点地标，图内**不要画木牌文字、不要画 UI、不要画发光**（均由 HTML/CSS 叠加）。
