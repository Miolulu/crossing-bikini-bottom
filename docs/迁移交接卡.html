4. 唯一未完事项：GitHub 推送（桌面端最可能要接着做的）

根因（已穷尽排查）：桌面应用「登录 GitHub 账号」≠ 沙箱会话的「GitHub 连接器 OAuth 授权」，网关持续返回 17009 Connector "github" is not authorized。网络实测：github.com 网页与设备码端点超时；api.github.com REST 可达（仅差认证）。

在桌面端（你已登录、网络策略不同）通常更容易成功，二选一：

  • A. 连接器授权：桌面端「设置 → 连接器 → GitHub」完成 OAuth，然后执行 ./tools/push-to-github.sh <owner/repo>（Token 仅在进程内传递，不落盘）。
  • B. PAT + REST（推荐，最稳）：生成一个 fine-grained PAT（只授目标仓库 Contents: read/write；需新建仓库再临时开 Administration: write），执行：
GITHUB_PAT=<token> python3 tools/push-rest.py                # 推到 <用户名>/bikini-bottom
GITHUB_PAT=<token> python3 tools/push-rest.py owner/repo     # 推到指定仓库
python3 tools/push-rest.py --check                           # 离线自检（不联网）

push-rest.py 走 GitHub Git Data API，一次 commit 导入全部 50 个文件 / 18 张 PNG / 29.04 MB，不依赖连接器、不依赖 github.com。不要把 Token 写进任何仓库文件。

  • C. 兜底：直接在 GitHub 网页上传交付包 zip。
美术 AI 不需要任何 GitHub 授权，只按 assets/README.md 往 assets/ 放 PNG、改 manifest.json。
