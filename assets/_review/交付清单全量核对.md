## 三、可直接省积分的 58 张 + 6 条

`delivery.note` 原文：**「code_only=true 的条目不需要交付；default=css 的条目已由 CSS 实现，交了才替换」**。

| 类别 | 条目 | 张数 |
|---|---|---|
| `default=css` | G-06(6) D-10(6) F-16/17/18/19(4) G-05(27) G-07(3) G-09(2) G-10(3) G-11(5) G-12(2) | **58** |
| `code_only` | E-01 / G-08 / G-13 / F-01 / F-07 / F-20 | **0** |

**这 58 张不需要花任何积分**，demo 里已经用 CSS/SVG/HTML 实现且能跑。用户说「很多美术资产应该都是用 css 搭的」——仓库契约正是这么设计的，之前我给的《可选资产清单与节省量》只覆盖了其中一部分。
